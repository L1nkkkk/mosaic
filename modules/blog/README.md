# 博客模块使用说明

「博客」模块在页面上列出最近的文章，点开后在单独的页面 `/post/<名称>` 阅读。文章不在编辑台里写：它们是一个 GitHub 仓库里的 Markdown 文件，推送后由服务器同步过来。

实现细节见 [模块开发手册](../../docs/MODULES.md) 的「博客模块」和 [HTTP 接口参考](../../docs/HTTP-API.md) 的「博客接口」。

## 1. 第一次设置

1. 准备一个 GitHub 仓库放文章，里面建一个 `posts/` 目录。
2. 在服务器的环境配置（`/etc/mosaic/app.env`，本地是 `.env`）里加上仓库：

   ```sh
   BLOG_REPO=owner/name
   # 可选：分支不是 main 时
   BLOG_BRANCH=main
   # 可选：私有仓库必须填，只读权限即可；公开仓库填了可以提高 GitHub 的请求额度
   BLOG_TOKEN=github_pat_…
   ```

   修改后要重建容器才生效（下一次自动部署会带上）。没有配置时模块显示为空，应用照常启动。
3. 在编辑台「＋ 添加模块」→「博客」，把显示范围改成「两个空间共用」或「仅公开空间」，然后「发布」。

访客只有在公开页发布了博客模块之后才能读到文章和图片。撤下模块，所有文章地址随之返回 404。

模块自己的设置只有三项：标题、显示篇数（1–30）、只显示某个标签（可选）。同一页可以放多个实例，比如一个显示全部、一个只显示「技术」。

## 2. 写一篇文章

在仓库的 `posts/` 下新建一个 Markdown 文件，提交并推送。文件名决定文章地址：

```text
posts/2026-10-13-hello.md      →  /post/hello
posts/2026-10-20-你好 世界.md   →  /post/你好-世界
```

文件名开头的日期会被去掉，其余部分转成小写，空格和下划线变成连字符。改文件名等于改地址，旧地址会失效。只有 `posts/` 这一层的 `.md` 和 `.html` 文件算文章，子目录里的不算。

文件开头可以写这些信息，都是可选的：

```markdown
---
title: 文章标题
date: 2026-10-13
tags: [随笔, 技术]
summary: 列表里显示的一句话摘要。
draft: true
---

正文从这里开始。
```

| 字段 | 没写的时候 |
| --- | --- |
| `title` | 用正文第一个 `# 一级标题`（并从正文里去掉），再没有就用文件名 |
| `date` | 用文件名开头的日期；都没有的文章排在最后 |
| `tags` | 没有标签。也可以写成每行一个 `- 标签` 的列表，最多 8 个 |
| `summary` | 取正文第一段，超过 160 字截断 |
| `draft` | 默认公开。`true` 的文章不会同步到站点 |

如果仓库是公开的，草稿在 GitHub 上仍然能被看到，`draft` 只是不让它出现在站点上。

### 整页 HTML 文章

`posts/` 里也可以直接放一个完整的 `.html` 文件，适合带动画和交互的课件、演示。它和 Markdown 文章排在同一个列表里，带「可交互」标记；点开后整屏显示这个页面，保留它自己的版式。

```text
posts/2026-10-13-vulkan-frame-loop.html   →  /post/vulkan-frame-loop
```

文章信息写在页面的 `<head>` 里，除了标题都可以省略：

```html
<title>Vulkan 帧循环入门</title>
<meta name="tags" content="Vulkan, 课件">
<meta name="description" content="列表里显示的一句话摘要。">
<meta name="date" content="2026-10-13">
<meta name="draft" content="true">
```

没写 `date` 时用文件名开头的日期。

页面在隔离环境里运行，碰不到站点的登录状态，因此有这些约束：

- **要自包含**：样式和脚本写在页面里。外部脚本（CDN 上的库）不会加载；HTTPS 的样式表、字体和图片可以用。
- **图片**用 `data:` 内嵌或 HTTPS 外链，不能引用仓库里的相对路径文件。
- **不能联网**：页面里的 `fetch` 等请求会失败。
- **不能存东西**：`localStorage`、Cookie 不可用，页面不能靠它们记住进度。
- 指向外部的链接会在新标签页打开，页内锚点正常跳转。
- 明暗外观由页面自己决定（比如跟随系统），不跟随站点右上角的切换按钮。
- 单个文件最大 1 MB。

## 3. 图片和链接

- **图片**放进仓库，用相对于文章的路径引用：`![说明](img/photo.png)`。支持 PNG、JPG、GIF、WebP、AVIF，单张不超过 5 MB。
- **外链图片不会显示**，会变成一个指向原地址的链接。站点的安全策略只允许加载本站的图片。
- **链接到另一篇文章**，直接写它的文件：`[上一篇](2026-10-01-other.md)`，线上会变成站内地址。
- 其他链接只支持 `https://`、`http://` 和 `mailto:`，在新标签页打开。

## 4. 支持的 Markdown

标题、段落、粗体、斜体、删除线、行内代码、代码块、引用、有序和无序列表（可嵌套）、任务列表、表格、分隔线、链接、图片。

需要知道的几点：

- 文章里的 HTML 标签不会生效，会按原样显示成文字。
- 代码块没有语法高亮。
- 文章标题是页面的一级标题，所以正文里的 `#` 显示为二级，`##` 显示为三级，以此类推。
- 中文段落里的换行不会变成空格；行尾加两个空格或反斜杠是强制换行。
- 不支持脚注、数学公式、高亮 `==文字==`。

## 5. 用什么写

文章就是普通文件，任何编辑器都可以。

### VS Code

打开文章仓库的文件夹即可。

- `Ctrl+K V` 分屏预览。
- 截图后在 `.md` 里直接 `Ctrl+V`，VS Code 会把图片存成文件并插入相对路径引用。在仓库的 `.vscode/settings.json` 里加一条，让图片统一存到 `posts/img/`：

  ```json
  { "markdown.copyFiles.destination": { "posts/**/*": "img/" } }
  ```

- 写完在「源代码管理」里提交并推送。

### Obsidian

把文章仓库的文件夹当作库打开。**先改三个设置**（设置 → 文件与链接），否则图片和链接在线上不显示：

| 设置项 | 改成 |
| --- | --- |
| 使用 Wiki 链接 | 关闭 |
| 内部链接类型 | 基于当前笔记的相对路径 |
| 附件默认存放路径 | 当前文件所在文件夹下的子文件夹，名称填 `img` |

其他注意事项：

- Obsidian 专有的语法线上不支持：`[[双链]]`、`![[嵌入]]`、Callout（`> [!note]` 会变成普通引用并多出 `[!note]` 字样）、`==高亮==`、`%%注释%%`。
- 「属性」面板写出来的 `title`、`date`、`tags` 可以直接识别。
- Obsidian 自己不会推送。可以装社区插件 Obsidian Git，或者写完后在终端里提交推送。开了自动推送的话，没写完的文章记得加 `draft: true`。
- 把 `.obsidian/` 加进仓库的 `.gitignore`，避免把窗口布局等个人配置推上去。

### 不在电脑前

在 GitHub 的仓库页面按 `.` 键打开网页版编辑器，手机浏览器也能新建和修改文件，提交即发布。适合改错别字或发纯文字的短文。

## 6. 同步是怎么进行的

- 服务器每 5 分钟检查一次分支的最新提交，所以推送后最多等几分钟。着急的话，在编辑台打开博客模块的设置，点「立即同步」。
- 同一处也能看到当前连接的仓库、文章数、上次同步时间，以及最近一次失败的原因。
- 只下载改动过的文件；没有变化时不占用 GitHub 的请求额度。
- 同步只访问 `api.github.com`。GitHub 连不上时保留上一份，访客读到的始终是服务器上的副本，不受影响。
- 文章不需要在编辑台「发布」，同步完成就上线。

## 7. 限制

| 项目 | 上限 |
| --- | --- |
| 文章数 | 300 篇，超出时保留文件名排在后面的（日期较新的） |
| 单篇大小 | Markdown 256 KB，HTML 页面 1 MB，超出的文章会被跳过 |
| 单张图片 | 5 MB，超出的图片不显示 |
| 图片总数 | 400 张，超出时整次同步失败并在编辑台提示 |

`DATA_DIR/blog` 只是仓库的副本，丢失后会重新同步，不需要备份。

## 8. 排查

| 现象 | 先检查 |
| --- | --- |
| 模块显示「还没有连接博客仓库」 | 没有设置 `BLOG_REPO`，或设置后容器还没有重建 |
| 推送后文章没出现 | 是否已过 5 分钟；文件是否直接在 `posts/` 下并以 `.md` 或 `.html` 结尾；是否写了 `draft: true`；编辑台里有没有同步失败的提示 |
| 提示找不到仓库或分支 | `BLOG_REPO` 是否为 `owner/name` 形式；分支名；私有仓库是否配置了 `BLOG_TOKEN` |
| 提示请求次数已用完 | 未登录的额度是每小时 60 次，通常是频繁点「立即同步」造成的；等一小时或配置 `BLOG_TOKEN` |
| 图片不显示 | 是否为外链；路径是否相对于文章；格式和大小是否在支持范围内；是否用了 `![[...]]` 写法 |
| 访客打开文章是「没有这篇文章」 | 博客模块是否已发布到公开空间；文件是否改过名 |
| HTML 页面打开后缺样式或不能交互 | 是否依赖了外部脚本、相对路径的文件、网络请求或 `localStorage`，见「整页 HTML 文章」 |
| 两篇文章只出现一篇 | 去掉日期后的文件名相同，地址冲突，只保留其中一篇 |
